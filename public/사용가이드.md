# 알플레이 캔버스툴 처음 사용 가이드

처음이라면 **[실제 화면으로 따라하기](화면가이드.md)**에서 작품 추가부터 캔버스 검증까지 순서대로 확인하세요.

각 입력란이 캔버스 어디에 들어가는지는 **[화면별 입력 항목 가이드](화면별가이드.md)**를 보세요. 화면과 필드 설명이 함께 들어 있는 이미지도 제공합니다.

화면의 `?` 버튼에서 해당 기능의 설명을 볼 수 있습니다. 오른쪽 관리 영역의 **처음 사용 가이드**에서 전체 작업 순서를 확인하고 이 문서를 내려받을 수 있습니다.

## 먼저 알아둘 말

| 이름 | 뜻 |
| --- | --- |
| 작품 원본 | 캐릭터 설정·프롬프트·로어북 화면에서 저장하는 자료 |
| 캔버스 | 알플레이의 노드와 연결선을 담은 JSON 파일 |
| 노드 | 인물·스토리·변수처럼 캔버스에 놓이는 하나의 항목 |
| 허브 | 여러 자료 노드를 묶어 스토리에 연결하는 노드 |

## 작업 흐름

**작품 선택 → 자료 작성·저장 → 기준 캔버스 열기 → 노드 추가·갱신·연결 → 수정본 다운로드 → 알플레이에 가져오기 → 왕복 검증**

처음에는 작품 하나와 인물 하나, 시작 노드 하나로 흐름을 익혀 보세요. 허브·변수·업적은 작품에 필요할 때 추가하면 됩니다.

## 처음 사용 가이드

작품 자료를 먼저 작성하고 저장한 뒤, 알플레이에서 내보낸 캔버스에 반영하는 도구입니다.

1. 상단 현재 작품을 눌러 작품을 선택하세요. 처음이라면 선택창 아래의 새 작품 추가에서 이름을 입력합니다.
2. 캐릭터 설정·작품 프롬프트·로어북에서 필요한 내용을 작성하고 저장하세요. 상태창이 필요하면 HTML 에셋도 준비합니다.
3. 여러 노드를 묶어 연결하려면 허브 관리에서 IN 대상과 OUT 스토리를 선택하고 저장하세요. 허브는 필요할 때 사용하면 됩니다.
4. 알플레이에서 캔버스 JSON을 내보내고, 이 도구의 알플레이 캔버스 → 콘텐츠 편집 → 기준 캔버스에서 여세요.
5. 탭별로 누락 노드를 추가하고 기존 내용을 갱신하세요. 허브를 사용한다면 노드를 준비한 다음 허브 추가·허브 연결을 합니다.
6. 수정본 다운로드로 결과 JSON을 받으세요. 알플레이에 가져온 뒤 다시 내보낸 파일과 왕복 검증을 하면 본문 누락을 확인할 수 있습니다.

**확인:** 자료 화면의 저장은 작품 원본에 반영됩니다. 캔버스 화면의 편집은 수정본 다운로드를 해야 파일로 받을 수 있습니다.

## 작품 선택·추가

작품은 캐릭터·프롬프트·로어북 등 자료를 나누어 보관하는 단위입니다.

1. 상단 현재 작품 이름을 누르면 작품 선택창이 열립니다.
2. 기존 작품을 검색해 선택하거나, 창 아래의 새 작품 추가를 누르세요.
3. 새 작품명을 입력하고 작품 추가를 누르면 새 작품으로 전환됩니다. 이름 변경은 각 작품 옆 버튼에서 할 수 있습니다.

**확인:** 작업하기 전에 상단 작품 이름을 확인하세요. 이름 변경에서 폴더명까지 바꾸면 실제 저장 폴더 이름도 변경됩니다.

## 캐릭터 설정

인물 노드의 이름·중요 정보(300토큰)·상세 설명(30,000토큰)을 관리합니다.

1. 캐릭터를 추가하거나 목록에서 기존 인물을 선택하세요.
2. 중요 정보에는 말투·성격·행동 패턴을, 상세 설명에는 자세한 특징과 배경을 작성하고 저장하세요.
3. 알플레이 캔버스의 인물 탭에서 저장된 내용을 비교하고 추가·갱신하세요.

**확인:** 캔버스에 새 인물을 추가하면 감정·성·특수용 빈 이미지 노드 3개도 연결됩니다. 실제 이미지 파일은 알플레이에서 넣습니다.

## 작품 프롬프트

작품 전체에 공통으로 적용할 지침과 각 시작·일반 스토리의 내용을 작성합니다.

1. 노드 추가에서 이름과 시작·일반 종류를 정하세요. 기존 노드는 노드 설정에서 변경합니다.
2. 메인 프롬프트, 에디셔널, 전체 스토리를 작성하세요. 시작 노드는 시작 가이드·시작 메시지도 작성합니다.
3. 저장을 누른 뒤 캔버스의 스토리 비교 탭에서 반영하세요. 변수와 업적은 별도 탭에서 관리합니다.

**확인:** 각 노드의 메인 + 에디셔널로 적용됩니다. 중요 정보는 메인과 에디셔널을 합쳐 4,300토큰 기준입니다. 메인은 작품 공통이며, 에디셔널·전체 스토리·시작 내용은 선택한 노드별로 저장됩니다.

## 로어북

장소·세력·설정처럼 필요할 때 사용할 정보를 항목별로 정리합니다.

1. 항목을 추가하고 분류·제목·호출 키워드·본문을 작성하세요.
2. 호출 키워드는 해당 내용과 직접 관련된 단어로 정하고 저장하세요.
3. 캔버스의 로어북 탭에서 누락 항목을 추가하거나 변경된 내용을 갱신하세요.

**확인:** 작품 원본을 저장해도 이미 내려받은 캔버스 파일은 자동으로 바뀌지 않습니다. 캔버스에 다시 반영해 주세요.

## HTML 에셋

상태창에 사용할 HTML을 작성하고 미리보기로 확인하는 화면입니다.

1. 새 에셋을 만들거나 기존 에셋을 선택하세요.
2. HTML을 편집하고 미리보기에서 표시를 확인한 뒤 변경 저장을 누르세요.
3. 캔버스의 상태창 탭에서 에셋과 대응되는 노드를 추가·갱신하세요.

**확인:** 이름이 맞지 않거나 중복되면 자동으로 대응시키지 못할 수 있습니다. 미리보기 후 알플레이에서도 실제 표시를 확인하세요.

## 허브 관리

허브는 여러 자료 노드를 모아 스토리로 연결할 때 사용합니다. 이 화면에서는 연결할 대상 목록을 저장합니다.

1. 허브 이름을 입력해 추가하고, 편집할 허브를 선택하세요.
2. IN에서 로어북·인물·업데이트 규칙을 선택하고, OUT에서 연결할 시작·일반 스토리를 선택하세요.
3. 저장을 누르세요. 실제 캔버스 연결은 알플레이 캔버스 → 콘텐츠 편집 → 허브 관리에서 적용합니다.

**확인:** 현재 목록 전체 선택은 현재 필터에 보이는 대상에만 적용됩니다. 대상 본문을 복사하는 기능은 아닙니다.

## 알플레이 캔버스

작품 자료를 캔버스에 반영하거나, JSON의 본문과 노드 연결을 점검합니다.

1. 콘텐츠 편집: 기준 캔버스를 열고 자료를 추가·갱신한 다음 수정본을 다운로드합니다.
2. 왕복 검증: 업로드 직전 파일과 알플레이에서 다시 내보낸 파일의 본문을 비교합니다.
3. 노드 분석: 파일 하나의 스토리·변수·허브·고립 노드 구성을 살펴봅니다.

**확인:** 기준 캔버스는 알플레이에서 내보낸 JSON입니다. 작품 프롬프트 화면에서 내보낸 JSON과는 용도가 다릅니다.

## 메인 프롬프트

모든 시작·일반 노드에서 공통으로 사용할 작품 운영 지침입니다.

1. AI의 역할, 문체, 공통 진행 규칙을 작성하세요.
2. 특정 시작 장면에만 필요한 내용은 시작 가이드·시작 메시지에 작성하세요.
3. 저장한 뒤 캔버스의 스토리 비교에서 갱신하세요.

**확인:** 다른 노드를 선택해도 같은 메인을 사용하며, 각 노드의 메인 + 에디셔널로 적용됩니다.

## 에디셔널

각 노드의 메인 + 에디셔널 중 선택한 노드의 에디셔널을 작성합니다.

1. 편집할 시작·일반 노드를 선택하세요.
2. 이 노드에서 메인 뒤에 추가할 지침을 작성하고 저장하세요.
3. 캔버스의 스토리 비교에서 갱신하면 메인 뒤에 해당 노드의 에디셔널이 이어집니다.

**확인:** 메인은 작품 공통으로 공유하고, 에디셔널은 노드마다 따로 저장합니다.

## 전체 스토리

선택한 스토리 노드의 세계관과 배경을 작성합니다.

1. 편집할 노드를 먼저 선택하세요.
2. 해당 노드의 배경을 작성하고 저장하세요.
3. 캔버스 스토리 비교에서 전체 스토리·배경에 반영할 수 있습니다.

## 시작 가이드

선택한 시작 장면을 AI가 어떻게 진행할지 정하는 지침입니다.

1. 시작 노드를 선택하세요. 일반 노드에는 이 항목이 없습니다.
2. 초기 상황과 초반 진행에 필요한 지침을 작성하고 저장하세요.
3. 캔버스에 반영하면 해당 시작 노드의 시작 가이드가 갱신됩니다.

## 시작 메시지

대화를 시작할 때 보여줄 첫 장면의 본문입니다.

1. 시작 노드를 선택하세요.
2. 이용자가 읽을 첫 장면과 대사를 작성하고 저장하세요.
3. 캔버스에 반영하면 해당 시작 노드의 시작 메시지가 갱신됩니다.

## 변수·업데이트 규칙

소지금·호감도 등 상태값과 그 값을 바꾸는 지침을 관리합니다.

1. 변수 추가를 누르고 타입, 제목, 식별자, 초기값을 입력하세요. 예: 숫자 / 소지금 / gold / 100.
2. 업데이트 규칙을 추가해 값을 언제 어떻게 바꿀지 적고, 관련 변수를 선택하세요.
3. 수정 후 자동 저장 완료를 확인하세요. 캔버스에서는 변수·업데이트 규칙 탭을 통해 노드와 연결을 반영합니다.

**확인:** 변수·업데이트 규칙은 자동 저장됩니다. 저장 완료 표시를 확인한 뒤 다른 작품으로 이동하세요.

## 업적 관리

업적 이름과 설명, 달성 여부를 판단할 변수·조건을 등록합니다.

1. 업적을 추가하고 이름·설명을 입력하세요.
2. 감시할 변수와 조건·조건값을 정한 뒤 업적 저장을 누르세요.
3. 캔버스의 업적 탭에서 필요한 업적·트리거와 연결을 반영하세요.

**확인:** 업적은 이 화면의 업적 저장 버튼으로 저장합니다. 프롬프트 본문 저장과 구분해 주세요.

## 콘텐츠 편집

알플레이 캔버스와 현재 작품에 저장된 원본 자료를 비교해 반영합니다.

1. 자료 화면에서 내용을 먼저 저장하고, 기준 캔버스에 알플레이 내보내기 JSON을 선택하세요.
2. 탭별로 차이를 확인하고 필요한 노드를 추가하거나 원본으로 갱신하세요.
3. 마지막에 수정본 다운로드를 눌러 새 JSON을 받으세요.

**확인:** 편집 되돌리기는 불러왔던 기준 캔버스로 돌아갑니다. 화면에서 편집한 결과는 다운로드 전까지 원본 파일에 덮어쓰지 않습니다.

## 노드 추가·삭제

누락은 저장된 자료만 있는 항목, 레거시는 캔버스에만 있는 항목입니다.

1. 타입을 고르고 추가·삭제할 항목을 체크하세요.
2. 선택 추가 또는 선택 레거시 삭제를 누르세요. 모두 추가·삭제도 현재 필터 범위에만 적용됩니다.
3. 결과를 확인하고 수정본을 다운로드하세요. 중복 확인 항목은 이름과 원본을 먼저 점검합니다.

**확인:** 레거시라고 해서 반드시 불필요한 노드는 아닙니다. 삭제하면 연결선도 함께 제거되며, 편집 되돌리기로 이번 편집 전체를 취소할 수 있습니다.

## 인물·이미지 노드 추가

저장한 캐릭터 설정을 인물 노드에 반영합니다.

1. 캐릭터 설정에서 인물 내용을 작성하고 저장하세요.
2. 캔버스 인물 탭에서 기존 인물은 갱신하고 누락된 인물은 추가하세요.
3. 새 인물에는 감정·성·특수용 빈 이미지 노드 3개와 연결선이 함께 생깁니다. 실제 이미지는 알플레이에서 넣으세요.

**확인:** 기존 인물을 갱신하는 것만으로 이미지 노드가 추가되지는 않습니다.

## 캔버스에 허브 적용

허브 관리에서 저장한 구성을 실제 캔버스 노드와 연결합니다.

1. 다른 콘텐츠 탭에서 필요한 로어북·인물·규칙·스토리 노드를 먼저 추가하세요.
2. 저장된 허브를 선택하고 허브 추가를 누르세요. 구성을 수정했다면 저장된 허브 새로고침을 누릅니다.
3. 허브 연결을 눌러 대상 → 허브 → 스토리 연결을 만들고 수정본을 다운로드하세요.

**확인:** 연결 대상이 없거나 이름이 중복되면 안내를 확인해 먼저 해결하세요. 같은 연결은 중복으로 추가하지 않습니다.

## 왕복 검증

알플레이로 가져갔다가 다시 내보내는 과정에서 본문이 달라졌는지 비교합니다.

1. ①에는 알플레이에 업로드하기 직전의 JSON을 선택하세요.
2. ②에는 그 캔버스를 알플레이에서 다시 내보낸 JSON을 선택하세요.
3. 왕복 잘림 검증을 눌러 잘림·누락·변경을 확인하세요. 결과는 검증 JSON 다운로드로 보관할 수 있습니다.

**확인:** 로어북·인물·스토리 본문을 비교합니다. 정상 결과가 모든 연결이나 실제 대화 동작까지 보장하는 것은 아닙니다.

## 노드 분석

캔버스 안에 어떤 노드가 있고 어떻게 연결됐는지 살펴봅니다.

1. 분석할 캔버스 JSON을 선택하세요.
2. 캔버스 노드 분석을 누르세요.
3. 스토리 흐름, 변수·규칙, 허브 연결과 연결되지 않은 고립 노드를 확인하세요.

**확인:** 분석만 실행하며 파일은 변경하지 않습니다.

## 데이터 폴더

작품 자료를 읽고 저장할 폴더를 선택합니다.

1. 데이터 폴더를 펼쳐 현재 위치를 확인하세요.
2. 폴더 변경으로 기존 자료 폴더를 고르거나 기본 위치 사용을 누르세요.
3. 종료.cmd로 서버를 종료하고 실행.cmd를 다시 실행하면 새 위치가 적용됩니다.

**확인:** 폴더를 바꿔도 기존 자료를 이동·복사하지 않습니다. 필요한 자료가 들어 있는 폴더를 선택하세요.

## 작품 전체 MD 저장

저장된 프롬프트·로어북·캐릭터 본문을 하나의 문서로 내려받습니다.

1. 각 자료 화면에서 편집한 내용을 먼저 저장하세요.
2. 홈에서 작품 전체 MD 저장을 누르세요.
3. 다운로드된 Markdown 문서로 작품 본문을 한 번에 검토할 수 있습니다.

**확인:** 캔버스 JSON이나 이미지까지 포함한 전체 백업은 아닙니다. 전체 자료 백업은 데이터 폴더를 복사해 보관하세요.

## 저장 방식 한눈에 보기

| 작업 | 저장·반영 방법 |
| --- | --- |
| 캐릭터·프롬프트·로어북·허브 | 해당 화면에서 저장 |
| HTML 에셋 | 변경 저장 |
| 변수·업데이트 규칙 | 자동 저장 완료 표시 확인 |
| 업적 | 업적 저장 |
| 캔버스 콘텐츠 편집 | 수정본 다운로드 후 알플레이에 가져오기 |

## 자주 막히는 부분

- **새 작품을 만들고 싶어요:** 상단 현재 작품 이름 → 선택창 아래 새 작품 추가를 누르세요.
- **저장했는데 캔버스가 그대로예요:** 자료 저장 후 기준 캔버스를 다시 불러오고 해당 탭에서 추가·갱신한 다음 수정본을 다운로드하세요.
- **인물 이미지는 어디서 넣나요:** 인물 추가 시 생기는 3개 이미지 노드는 빈 묶음입니다. 실제 이미지는 알플레이에서 넣습니다.
- **허브 연결을 누를 수 없어요:** 저장된 허브를 선택하고 필요한 대상 노드가 캔버스에 있는지 확인하세요. 없는 대상·중복 이름 안내를 해결하고 허브를 추가한 뒤 연결합니다.
- **노드가 레거시라고 나와요:** 등록 원본과 연결되지 않은 항목이라는 뜻입니다. 필요한 노드일 수 있으므로 내용을 확인한 뒤 삭제하세요.
- **자료가 안 보여요:** 현재 작품과 데이터 폴더를 확인하세요. 데이터 폴더를 바꿨다면 서버를 종료하고 다시 실행해야 합니다.
